================================================================================
INSTALLATION REPORT - VOIP IVR PROJECT 

PREREQUISITES:
Asterisk PBX must be installed and running on the system.
SIP softphones (Linphone) should be configured and registered.
Python 3 must be installed on the system to execute the AGI scripts.

REQUIRED LIBRARIES:

The AGI scripts require specific Python libraries to handle web scraping for real-time data (e.g., Euromilhões results). Python must be able to use:

import requests

from bs4 import BeautifulSoup

To install these required dependencies, run the following command in your terminal:
sudo pip3 install requests beautifulsoup4

CONFIGURATION FILES INSTALLATION:

To configure the SIP users and dialplan logic, you must replace the default Asterisk configuration files with the pre-configured ones provided in the ZIP package.

Files: sip.conf and extensions.conf

Target Path: /etc/asterisk/

Permissions: Must be owned by the asterisk user.

Run these commands:
sudo cp sip.conf extensions.conf /etc/asterisk/
sudo chown asterisk:asterisk /etc/asterisk/sip.conf /etc/asterisk/extensions.conf


AUDIO FILES INSTALLATION:

The custom audio prompts (*.gsm files) used for the menus and game updates must be moved to the directory defined by the PROJECT_AUDIO_DIR global variable.

Target Path: /home/mint/sound

Permissions: Grant ownership to the asterisk user so the PBX can read the files.

Run these commands:
sudo mkdir -p /home/mint/sound (if the directory doesnt already exist)
sudo cp *.gsm /home/mint/sound/
sudo chown asterisk:asterisk /home/mint/sound/*.gsm

AGI SCRIPTS INSTALLATION:

The Python AGI scripts handling the core logic of the system must be moved to the directory defined by the PROJECT_AGI_DIR global variable.

Scripts: euromilhoes_agi.py, lunar_game.py, and lunar_stats.py

Target Path: /home/mint/scripts

Permissions: Scripts must be owned by the asterisk user and marked as executable.

Run these commands:
sudo mkdir -p /home/mint/scripts (if the directory doesnt already exist)
sudo cp euromilhoes_agi.py lunar_game.py lunar_stats.py /home/mint/scripts/
sudo chown asterisk:asterisk /home/mint/scripts/*.py
sudo chmod +x /home/mint/scripts/*.py
